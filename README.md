🎵 Clone do Spotify 

Este projeto é uma réplica da interface do Spotify, desenvolvido como parte do curso "Desenvolvimento Web Completo" da Udemy. Utiliza HTML, CSS,
JavaScript e Bootstrap para criar uma experiência visual semelhante à plataforma original. 

🔧 Tecnologias Utilizadas 

HTML5 

CSS3 

JavaScript 

Bootstrap 

🎯 Funcionalidades 

Layout responsivo inspirado no Spotify 

Navegação entre seções (Home, Buscar, Sua Biblioteca)
